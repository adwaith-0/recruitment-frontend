# Homepage reference

The homepage follows the screenshot supplied by the user, with the existing recruitment assistant embedded as a floating chat widget.

The following original assets were downloaded from the [Apprenticeship Connect employers page](https://apprenticeshipconnect.co.uk/apprenticeship-recruitment/):

- `public/images/apprenticeship-connect-logo.png`: https://apprenticeshipconnect.co.uk/wp-content/uploads/2024/02/Apprenticeship-Connect-01-600x148.png
- `public/images/apprenticeship-team.png`: https://apprenticeshipconnect.co.uk/wp-content/uploads/2023/12/Untitled-design-2023-12-18T105636.136-1024x1024.png
- `public/images/ac-favicon.png`: https://apprenticeshipconnect.co.uk/wp-content/uploads/2024/03/cropped-Apprenticeship-Connect-Favicon-32x32.png
- `public/images/social-*.svg`: original social icons from the reference page.
- `public/fonts/dm-sans-regular.woff2`: https://apprenticeshipconnect.co.uk/wp-content/themes/twentytwentythree/assets/fonts/dm-sans/DMSans-Regular.woff2
- `public/fonts/dm-sans-bold.woff2`: https://apprenticeshipconnect.co.uk/wp-content/themes/twentytwentythree/assets/fonts/dm-sans/DMSans-Bold.woff2

The homepage uses the reference site's bundled DM Sans as a local fallback to its hosted brand typography.

Navigation, social links, registration and Bud Login link to the original service. No third-party tracking scripts are embedded. The chat retains the existing local bridge and citation behavior.
